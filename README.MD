NexaAI – AI-Powered Content Creation Platform

NexaAI is a full-stack web application that provides AI-powered tools for content creation and image processing. It helps users generate articles, blog titles, images, and receive AI-based resume feedback through a unified dashboard.

Technologies Used

Frontend: React.js, Vite, Tailwind CSS

Backend: Node.js, Express.js

Database: Neon (PostgreSQL)

Authentication: Clerk

AI Services: Google Gemini, OpenAI

Media Services: Cloudinary, Clipdrop API

Features

AI Content Generation: Generate articles and blog titles using AI.

Image Generation & Editing: Create images from text, remove backgrounds, and remove objects.

Resume Review: Get AI-powered feedback on resumes (PDF).

User Authentication: Secure login and session handling using Clerk.

Dashboard: Centralized access to all AI tools and user content.
